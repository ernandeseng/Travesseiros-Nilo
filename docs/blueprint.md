# **App Name**: Nilo Comfort

## Core Features:

- Product Catalog: Showcase a variety of pillows and textile products.
- About Us: Tell the story of Nilo Travesseiros, highlighting milestones and vision.
- Customer Testimonials: Display customer reviews and ratings to build trust.
- Contact Form: Enable customers to easily contact Nilo Travesseiros for inquiries.
- Request a Quote: Allow customers to request personalized quotes for specific products.

## Style Guidelines:

- Primary color: Vibrant red (#E53935), the brand's main color, evokes energy and passion.
- Background color: Light gray (#F5F5F5), a soft and neutral backdrop.
- Accent color: Soft green (#4CAF50), used for secondary CTAs, symbolizes trust.
- Headings: 'Montserrat' sans-serif font for titles (bold, extrabold) gives a modern, solid appearance.
- Body: 'Inter' sans-serif font for body text (regular, medium), is clean and readable.
- Use modern line icons to represent features and benefits.
- Implement a clean, modern layout with a focus on visual hierarchy.
- Subtle animations such as fade-ins and parallax scrolling will enhance user engagement.
